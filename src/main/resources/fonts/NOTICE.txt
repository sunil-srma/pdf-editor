Bundled fonts
=============

The font files in this directory are unmodified copies of the upstream fonts (taken from the Debian /
Ubuntu font packages). They are used by the PDF editor to draw text in the exported PDF and are also served
to the browser (GET /api/fonts/files/<file>) so that the live preview uses exactly the same glyphs.

To add a family, put its static TTF/OTF files here, keep its licence text next to them and declare it in
com.example.pdfeditor.service.FontCatalog. Variable fonts are not supported (the PDF library embeds only the
default instance), so use static Regular / Bold / Italic / Bold Italic files.
